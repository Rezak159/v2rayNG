# Чек-лист форка A4VPN

Список того, что форк добавил или изменил поверх upstream v2rayNG. Проходить руками после
каждого мёржа upstream-тега (см. раздел «Upstream merges» в CLAUDE.md) и перед выкладкой
альфы. Автотестов на большинство пунктов нет — ломается это молча.

## Идентичность и сборка

- [ ] `applicationId` = `com.a4vpn.app.alpha` (+ суффикс флейвора), имя приложения — A4VPN.
- [ ] Имена APK: `A4VPN-Alpha_<version>_<abi>.apk`; арифметика versionCode в
      `applicationVariants.all` не потеряна.
- [ ] Сборка падает с внятным сообщением без `V2rayNG/a4.properties`
      (`a4.telegramBotUrl` / `a4.siteUrl`); в CI подставляются секреты.
- [ ] Release `signingConfig` не регистрируется без `signing.properties` (сборка debug
      без ключей проходит).
- [ ] Kotlin читает ссылки через `AppConfig.TELEGRAM_BOT_URL` / `AppConfig.SITE_URL`,
      не через `BuildConfig` напрямую.
- [ ] Обновлён `libv2ray.aar` под тег сабмодуля `AndroidLibXrayLite`, если тот сдвинулся.

## Дизайн A4

- [ ] Тема A4 (`ui/A4Theme.kt`) не перебита системной палитрой Monet — проверить на
      Android 12+ и в светлой, и в тёмной теме.
- [ ] Экраны на `AppTheme` (настройки, редакторы серверов, подписки) визуально не разъехались
      после upstream-правок `ui/compose/Theme.kt`.
- [ ] Liquid Glass нижняя навигация: фон, скругления, поведение при скролле.
- [ ] Power button на главном: анимация, состояния подключения/ошибки.
- [ ] Шиммер на имени сервера, шкала пинга.
- [ ] Красный акцент A4 в управлении исключениями приложений.

## Первый запуск и вход

- [ ] Экран первого запуска (`A4MainScreen`) показывает три действия: «У МЕНЯ ЕСТЬ КЛЮЧ»,
      «ПОЛУЧИТЬ КЛЮЧ В TELEGRAM» и подсказку про ссылку от пригласившего.
- [ ] Кнопки ведут на актуальные `TELEGRAM_BOT_URL` / `SITE_URL`.
- [ ] Импорт по ссылке: deeplink `import.a4secure.xyz/app/sub/…` и вставка ключа из буфера
      (баннер, скрытие баннера запоминается по отпечатку ссылки).

## Подписки и бесплатный доступ

- [ ] Флаг `FREE_SUBSCRIPTION_ENABLED` и поведение бесплатного профиля.
- [ ] Режим «только Telegram» (`PREF_TELEGRAM_ONLY_MODE`): маршрутизация в ядре, состояние
      переживает перезапуск, корректно работает на устройстве без Telegram.
- [ ] Отключённый бесплатный профиль, восстановленный из бэкапа, удаляется.
- [ ] Анонимная телеметрия обновления подписки уходит на `TELEMETRY_URL` и не ломает работу
      при недоступном бэкенде.

## Обход туннеля по приложениям

- [ ] Серверный список (`BYPASS_APP_LIST_URL`) подтягивается после обновления подписки
      через `BypassAppListManager`, запрос идёт мимо туннеля.
- [ ] Снятые вручную пакеты не возвращаются при следующем обновлении списка; баннер на экране
      выбора приложений и пункт меню возвращают их по явному действию.
- [ ] Первый список, уведший приложения из туннеля при включённом per-app, показывается
      разовой карточкой на главном экране (после вопроса о диагностике).

## Обновления и политика версий

- [ ] Проверка обновлений по `APP_UPDATE_MANIFEST_URL`, прогресс скачивания, напоминание про
      «неизвестные источники».
- [ ] Подписанная политика минимальной версии (`APP_POLICY_URL`): истечение срока и сетевые
      сбои не блокируют работу.
- [ ] Все запросы к бэкенду A4 идут через `DirectNetworkHttp` (мимо собственного VPN) —
      проверить при поднятом туннеле.

## Ядро и сервисы

- [ ] Подключение/отключение VPN, proxy-only и root-режимы после upstream-правок стартов сервисов.
- [ ] Нет крашей при старте VPN (регресс уже случался после мёржа 2.3.3).
- [ ] QS-тайл и ярлыки запускают и останавливают туннель.
